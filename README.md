# 流亡倖存者 · POE-survivor

[開啟遊戲](https://zoubao-355040.github.io/POE-survivor/) · 免下載，手機拖曳或用 WASD／方向鍵移動。

這是受《Path of Exile 1》啟發的非官方瀏覽器遊戲。選一顆自動使用的主動寶石，同組插槽可連上相容的輔助寶石。打開寶石背包會暫停戰場；「技能試射」可直接測任一主動技能，不必等升級抽到。擊殺為正在使用的主動及相容輔助提供經驗，低等寶石有追趕加成。

## v0.5.2：主線寶石商店、通貨與回城戰利品

- 普通寶石以角色需求等級和主線雙重解鎖。第一章依序在獅眼守望、暮光海灘、海潮地穴及布魯特斯後解鎖 1、4、8–10、12 級貨品；16 級以上貨品依後續章節放行。覺醒、特殊高階、瓦爾與變異不販售，仍可從試射場驗證技能。普通高階多重投射不是特殊寶石。
- 角色升級從蛻變石、改造石、增幅石、點金石、富豪石隨機顯示三種，選一種入倉；本版未開放裝備改造。
- 敵人掉落不必撿取。戰利品跨圖保留，回城或死亡回城時一次入帳：金幣進錢包、通貨和寶石進倉庫、裝備進背包。
- 海灘開局穿戴武器與胸甲。其他裝備穿上後才提供插槽；卸下時寶石留在持有寶石清單。

## v0.5.1：龍捲射擊呈現修正

- 龍捲射擊：主箭穿透，抵達各自的落點後有短暫旋風，並散射 3 支次級箭。多重投射增加主箭，每支主箭各自散射。
- 龍捲射擊．雲爆：單支載箭飛過敵人，抵達落點後向四周射出 9 支箭。多重投射增加落地箭數，不增加載箭。
- 兩種版本都可在「寶石 → 技能試射」比較。開啟試射會結束目前這局。

## v0.5.0：第一章可一局打完

序章後，第一章主線有 11 張可玩的地圖：暮光海灘 → 炙熱鹽沼 → 海潮地穴 → 沉寂海崖 → 碎岩山坡 → 禁靈之獄下層 → 禁靈之獄上層 → 監獄大門 → 魅影船墓 → 怨忿之窟 → 怨忿之窟深處。炙熱鹽沼需走近拾取三個雕紋，末關擊敗莫薇兒結束第一章。這是以 [PoE 1 第一章區域與主線](https://poedb.tw/tw/Act_1) 為骨架的倖存者版；支線與第二章未開放。

戰鬥中固定顯示王名及目前／最大生命。西拉克仍為教學強度；怒炎之使由 178 生命調整至 700，其後頭目按區域提高；沒有指定王的區域可清怪或撐到區域倒數。過關可直接進下一圖，或回鎮整理裝備再出發；死亡回鎮重試該圖，保留本局已取得的物品。本版沒有跨頁存檔，重開會結束本局，需要在選單再次確認。

## v0.4.2：正式地圖開始有混合怪群

暮光海灘依 [PoE 1 的區域怪物資料](https://poedb.tw/tw/The_Coast) 引入近戰食人族、噬火者與沿岸蟹。橘色地面圈是即將落下的火焰攻擊；怒炎之使用更大的火雨範圍。絕望岩灘的教學難度不變。原作客戶端的 [MonsterPacks 資料欄位](https://github.com/poe-tool-dev/dat-schema/blob/3feb69da17a8a3222e35edef46080d61243f05ee/dat-schema/_Core.gql#L4024) 記錄怪群適用區域與每群最少／最多數；本作暮光海灘目前的 60 隻總量、同時上限 12、補怪線 6 都是試玩設定，不是已驗證的原作生成數字。

## v0.4.0：從絕望岩灘到獅眼守望

開局普通攻擊，主動寶石和輔助寶石放在背包。可選教學，親手完成挑選、入槽、啟用主技能。沿海灘向右，擊敗西拉克才能進城。西拉克有 25% 機率只給 2–3 金幣，其他結果為 6–9 金幣、魔法或稀有裝備及一顆隨機通貨。普通怪仍各掉 1 金幣。

獅眼守望是安全區，可向寶石商指定購買、向賭商指定裝備部位，或在倉庫存取本局物品。裝備立即顯示詞綴，無需鑑定；通貨暫供存放。出鎮後是暮光海灘試煉。基礎怪量為 10 群 × 6 隻，分批出現。場上最多 12 隻普通怪，剩 6 隻（含）就立即補到 12，至多補到本關預備怪用盡。尾王也佔一個場上名額；若時間到時場上已滿，暫退一隻小怪騰位，有空位才回場。最後一群生成後全清，或戰鬥時間先到 120 秒，怒炎之使就登場；擊殺尾王即可通關，不必清光剩下的小怪。此歷史版本曾在升級時開寶石商店，已在 v0.5.2 改為通貨三選一。開場地名取自 [遊戲區域資料](https://poedb.tw/tw/The_Twilight_Strand)。

## v0.3.3：金幣與升級商店

普通敵人固定掉 1 金幣。走近可拾取；升級前地上的金幣也會結算到錢包。每次角色升級會暫停戰鬥並開啟商店，所有未持有的主動寶石及輔助寶石可搜尋、指定購買，不再抽三選一。可以多買，也可以把錢留到下次。新寶石放入背包，不會自動改掉目前的技能配置。

## v0.3.2：開局紅水和藍水

- 開局兩瓶皆滿充能；每殺一隻普通敵人，兩瓶各補 1 充能。
- 小型生命藥劑：最多 21 充能，消耗 7，3 秒回復 70 生命。小型魔力藥劑：最多 24 充能，消耗 6，3 秒回復 50 魔力。基底取自 [PoE 1 遊戲資料](https://github.com/PathOfBuildingCommunity/PathOfBuilding/blob/v2.68.0/src/Data/Bases/flask.lua)。
- 本作把「充能滿時使用」預設給兩瓶。滿血／滿魔時不扣充能，留到有缺額就自動喝，不設百分比門檻。回滿即停止回復。開背包、選獎勵時，藥劑也會暫停。

## v0.3.0

- 依 PoE 1 **3.30** 遊戲資料快照收錄 **145 個投射物主動技能／變體**及 **46 個投射物或直接相關輔助**。繁中介面內建可搜尋的圖鑑；瓦爾、變異、覺醒及高階寶石分開列。
- 攻擊和法術共用回合與傷害引擎，分別使用攻擊速度與施放速度；投射物飛行時間與速度共同決定飛行距離。
- 將扇面多重投射、平行齊射、逐發彈幕、指定目標射擊、散彈、裂化、穿透、分裂、連鎖、返回與落點效果分開處理。地雷、圖騰、砲塔與陷阱在戰場上有自己的發射時點。
- 這是按身為倖存者遊戲而調整的重製，不等同原作的完整戰鬥模擬。分類、初始魔力與可取得基礎數值來自快照；飛行比例、寶石經驗門檻、配裝與若干次要效果為這個遊戲的設計。詳見[研究與改編範圍](docs/projectile-design.md)。

## 本機驗證

```sh
node --test engine/*.test.mjs
python3 -m http.server 8123
```

在另一個終端機：

```sh
npm install --no-save --package-lock=false playwright@1.57.0
npx playwright install chromium --only-shell
node scripts/browser-smoke.mjs
```

對已發布版本測試時，把 `GAME_URL` 設為上方的遊戲網址。
