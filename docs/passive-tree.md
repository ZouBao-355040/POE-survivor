# 主天賦樹 · PoE 1 3.30.0

取自 [Grinding Gear Games 主天賦樹匯出](https://github.com/grindinggear/skilltree-export/blob/3.30.0/data.json)。沿用節點編號、群組、座標基準、相鄰關係、專精效果 ID；不搬運圖示、背景或遊戲素材。顯示層保留官方原文作為搜尋及未翻譯效果的後備。遊戲目前不是 1:1 的 PoE 戰鬥模擬器。

## 範圍與完成定義

- 共用主樹 2,321 個節點，含 7 個職業起點、48 個關鍵天賦、315 個專精位置。昇華、異界天賦、珠寶生成的樹、賽季樹不屬於這份主樹。
- 開新局時可選起點，預設遊俠。同一局配置後不切換職業。各職業目前共用岩灘開局裝備與寶石。
- 只有每一條詞綴都有對應運算的節點才可配置；不會為了通路而讓玩家支付點數買空白效果。「沿可用連線尚需…」不經過未接入節點。
- 重要天賦亮起後，才能選該群的一個專精效果。即使多個群組顯示同一效果，也只能配置一次；專精不會當作通行節點。
- 尚未實作的效果仍可搜尋比對。珠寶孔預留、不扣點。退點、昇華與跨重整存檔目前未開放。
- 沒有現行遊戲來源的條件（例如戰吼、詛咒、盾牌狀態、保留、部分召喚機制）不能靠空白旗標判定完成。新增支援後需驗證對戰鬥結果的正、反兩路影響。

## 重現和驗證

```sh
curl -fL https://raw.githubusercontent.com/grindinggear/skilltree-export/3.30.0/data.json -o /tmp/poe-tree.json
python3 scripts/import-passive-tree.py /tmp/poe-tree.json
node --test engine/*.test.mjs
node scripts/balance-act-one.mjs
```

匯入器核對指定來源 SHA256。同一效應只能用同一個效應 ID，不用翻譯名稱判定。調整詞綴映射時請檢查可達路徑、類別隔離、混合詞綴全支援、部位或武器條件、屬性門檻及相斥規則。瀏覽器 smoke 測試包含手機與桌面開局、進城、配置後血量與可用點數、篩選關鍵天賦與專精。
