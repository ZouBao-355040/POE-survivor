# 主天賦樹 · PoE 1 3.30.0

取自 [Grinding Gear Games 主天賦樹匯出](https://github.com/grindinggear/skilltree-export/blob/3.30.0/data.json)。沿用節點編號、群組、座標基準、相鄰關係、專精效果 ID；不搬運圖示、背景或遊戲素材。顯示層保留官方原文作為搜尋及未翻譯效果的後備。遊戲目前不是 1:1 的 PoE 戰鬥模擬器。

## 範圍與完成定義

- 共用主樹 2,321 個節點，含 7 個職業起點、48 個關鍵天賦、315 個專精位置。昇華、異界天賦、珠寶生成的樹、賽季樹不屬於這份主樹。
- 目前主線只開放遊俠。天賦起點隨角色職業固定，不能另選；其他職業的起點保留在共用主樹上供查看，但不開放配置。
- 只有每一條詞綴都有對應運算的節點才可配置；不會為了通路而讓玩家支付點數買空白效果。「沿可用連線尚需…」不經過未接入節點。
- 重要天賦亮起後，才能選該群的一個專精效果。即使多個群組顯示同一效果，也只能配置一次；專精不會當作通行節點。
- 尚未實作的效果仍可搜尋比對。珠寶孔預留、不扣點。退點、昇華與跨重整存檔目前未開放。
- 沒有現行遊戲來源的條件（例如戰吼、詛咒、盾牌狀態、保留、部分召喚機制）不能靠空白旗標判定完成。新增支援後需驗證對戰鬥結果的正、反兩路影響。

## 重現和驗證

```sh
curl -fL https://raw.githubusercontent.com/grindinggear/skilltree-export/3.30.0/data.json -o /tmp/poe-tree.json
python3 scripts/import-passive-tree.py /tmp/poe-tree.json
node --test engine/*.test.mjs
node scripts/balance-act-one.mjs
```

匯入器核對指定來源 SHA256。同一效應只能用同一個效應 ID，不用翻譯名稱判定。調整詞綴映射時請檢查可達路徑、類別隔離、混合詞綴全支援、部位或武器條件、屬性門檻及相斥規則。瀏覽器 smoke 測試包含手機與桌面開局、進城、配置後血量與可用點數、篩選關鍵天賦與專精。

## 瓦爾冥約（10808）

依 [GGG 規則](https://www.pathofexile.com/forum/view-thread/3531661#:~:text=Vaal%20Pact%20Keystone) 使用近戰擊中事件判定，而不看技能的「近戰」標籤。以閃電打擊為例，直接打擊立即回復生命偷取，同招的投射物照常分段回復。這不會把魔力偷取或靈能護體轉換出的護盾偷取也變成即時回復。戰鬥內紅水、生命再生、靈魂吸取和不可知論都無法回血；不可知論仍會在未滿血時犧牲魔力。回城及死亡重試屬於遊戲的重置流程，仍會補滿資源。

## 鬼舞（35255）與能量護盾專精

按 [GGG 3.16 鬼舞規格](https://www.pathofexile.com/forum/view-thread/3186390#:~:text=Give%20everyone%20access%20to%20Ghost%20Dance) 每 2 秒戰鬥時間獲得一層鬼影，最多 3 層。敵方未格擋的擊中完成傷害結算後消耗一層，按閃避值的 3% 回復護盾；閃避、躲避、格擋、持續傷害與致死傷害不觸發。新的護盾回復受最大護盾及閃避值兩者限制，包含充能、再生、偷取和甲殼的補盾，不會扣掉已在回復上限之上的護盾。新關卡與重試會重置鬼影計時；回城及重試補滿資源照舊。

專精效果 35810（每秒回復 2% 能量護盾）已使用同一回復上限，比例以最大能量護盾計算。它是再生而非充能，靈能護體仍不會禁止它。

## 擊中、擊殺與承傷回復

攻擊擊中回復以每名實際命中的敵人計算，即時生效；未命中或被格擋、法術、代打單位的直接擊中不會觸發。擊殺回復按結算的最後傷害來源，每名敵人只計一次；按照 [GGG 的擊殺歸屬說明](https://www.pathofexile.com/forum/view-thread/3123794#:~:text=Why%20are%20kills%20via%20hit) 區分代打單位直接擊殺和持續傷害擊殺，後者包含代打施加的持續傷害。擊殺經驗、藥劑充能、掉落等原規則不變。

承受的擊中傷害可按天賦在 4 秒內分段回復（生命回復專精可縮短至 3 秒），不同擊中各自計時並疊加。實際扣掉的護盾、魔力與生命都計入，未扣除的傷害、溢傷與持續傷害不計。瓦爾冥約阻止這些生命回復，但不影響魔力；護盾回復仍受鬼舞的閃避限制。

## 技能消耗效率

依 [GGG 3.29 版本說明](https://www.pathofexile.com/forum/view-thread/3985332) 區分效率和消耗降低；亦遵循 [3.29.1](https://www.pathofexile.com/forum/view-thread/3991633) 的順序，效率先於最終固定值調整。支援寶石先決定基礎整數消耗；同類效率加總後以 `1 + 效率` 作除數，消耗按資源個別取整。泛用及攻擊技能效率可影響生命消耗，魔力效率不會替血魔法省血。攻擊、生命專精的混合消耗從各自基礎值計算，不會把同一份成本重複扣除。異能魔力只從護盾代扣剩餘的魔力部分；不足以支付任何一項時整次施放不扣資源，生命消耗不能致死。施法迴響只在原始施放付款一次。此段不涉及光環保留或技能固有的反噬。

## 風魔舞者與絕對受難

- **風魔舞者（11239）**：依 [GGG 3.19 說明](https://www.pathofexile.com/forum/view-thread/3293287) 在命中結算前，檢查過去 4 秒是否被攻擊擊中。第一擊承受 20% 更少攻擊傷害；近期被擊中則承受 20% 更多，攻擊閃避機率有 10% 更多（不是增加面板閃避值）。依 [GGG 格擋修正](https://www.pathofexile.com/forum/view-thread/2907517)，成功格擋的攻擊仍更新近期狀態；閃避、法術或持續傷害不更新。
- **絕對受難（23407）**：依 [GGG 3.25 說明](https://www.pathofexile.com/forum/view-thread/3531661)，暴擊不用加成放大擊中傷害，改以當次暴擊加成作為點燃、流血和中毒的持續傷害乘數。非暴擊不能施加本作已實作的擊中異常狀態，也不會以保證冰凍或感電繞過。元素超載搭配時，擊中不施加異常。技能本身的非異常持續傷害仍保留，獨立冰緩地面照常、誘捕不是異常，召喚物不會拿到玩家本人的關鍵天賦。

## 箭舞（54922）與敵方弓箭

依 [GGG 3.19 規則](https://www.pathofexile.com/forum/view-thread/3293287) 對投射物**攻擊**的閃避值乘 2，對近戰**攻擊**的閃避值乘 0.75。法術（即使有投射物）和未標記為這兩類的攻擊不變。此倍率只在當次命中檢定使用，不會改變面板，也不會影響鬼舞的護盾回復值。第一章沉寂海崖有少量遠古之弓：瞄準方向先用紫色虛線預告，發射後箭矢沿路徑飛行，能走位閃開。碰到才進入正常攻擊結算，可以被閃避或格擋，不是延時法術。箭矢射程由飛行速度乘飛行時間決定，並設有數量上限，換圖、重試或回城會清空。
